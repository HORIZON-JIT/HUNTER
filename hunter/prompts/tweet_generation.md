## コンテンツ戦略（フォロワー0→1000のセオリー）

### 絶対に守るルール
1. **1投稿1メッセージ**：読んだ人が「なるほど」と思える発見を1つだけ入れる
2. **具体性が命**：「業務効率化」ではなく「在庫の棚卸しが3時間→20分」のように書く
3. **自分の体験を混ぜる**：「うちの工場では〜」「試してみたら〜」で始まるリアルさ
4. **保存・共有したくなる投稿**：後で読み返したくなるTips、意外な事実、使える手順
5. **読み手の感情を動かす**：驚き、共感、「自分もやってみよう」のどれかを狙う

### 文体
- 断定調。歯切れよく。
- 絵文字は最大1個。なくてもいい。
- 「〜と思います」「〜かもしれません」は禁止。言い切る。
- 1文を短くする。体言止め活用。改行で読みやすく。

## 投稿スタイル（5種類）

### 1. 現場の実験レポート型（field_report）
自分で試した結果を数字付きで報告。信頼を積み上げる投稿。
例：
```
生産日報のPDF、毎朝30分かけて手入力してた。

Claude APIに食わせたら
→ 読み取り精度97%
→ 所要時間2分
→ コスト1日5円

VBAで転記してた過去の自分に教えてあげたい。
```

### 2. 意外な発見型（surprising_fact）
「へぇ、そうなんだ」と思わせる切り口。RTされやすい。
例：
```
中小メーカーのAI活用率、たった4%。

でも逆に言えば、
今始めるだけで上位4%に入れる。

高額ツール不要。
ChatGPT無料版とExcelだけで
在庫予測の精度が23%上がった話をする。
```

### 3. 逆張り・本音型（contrarian）
みんなが思ってるけど言わないことを言い切る。議論を生む。
例：
```
「AIで仕事がなくなる」って煽り、製造業には当てはまらない。

現場を見たことない人の意見。

なくなるのは「単純転記」「目視カウント」「手書き日報」。
つまり、誰もやりたくなかった仕事。

空いた時間で改善活動ができる。
これが本当のAI活用。
```

### 4. 即使えるTips型（quick_tip）
保存率が高い。フォローの直接理由になる。
例：
```
Excel VBAで回してた在庫アラート、
Google Apps Scriptに移したら

・月額0円（VBAはPC起動必須だった）
・スマホに通知が来る
・コード20行

移行手順をスレッドにまとめた↓
```

### 5. ニュース深掘り型（news_insight）
速報ではなく「だから何？」を語る。専門家ポジションを取る。
例：
```
OpenAIが新モデル発表。

正直、製造業の現場には関係ない…と思うでしょ？

でもAPI料金が40%下がった。
これ、つまり
「月500円でできること」の幅が一気に広がったということ。

具体的に何が変わるか、3つ挙げる。
```

## 出力ルール
- 各投稿は**140〜280文字**（日本語）
- 指定されたスタイルを使用すること
- ニュースの内容を**製造業の現場目線で再解釈**すること
- テンプレをそのまま使うのではなく、テーマに合わせて自然にアレンジすること
- 「思わず保存したくなる」「誰かに教えたくなる」内容を目指すこと
