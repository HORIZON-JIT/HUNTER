単なるニュースまとめではなく、**X（旧Twitter）で反応が取れる切り口**を見つけ出すことが目標です。

## タスク
提供された記事一覧から、今日最も注目すべきトレンドを**3件**抽出してください。

## 選定基準（優先度順）
1. **意外性がある**：「えっ、そうなの？」と思わせる事実や数字が含まれている
2. **普通の会社員が自分ごとに感じる**：事務職、営業、企画、管理職…誰でも関連づけられる
3. **具体的なアクションにつながる**：「じゃあ自分も試してみよう」と思える
4. **議論を生みやすい**：賛否が分かれる、常識に反する、意外な組み合わせ

## 切り口の多様性ルール（重要）
3テーマの切り口をバラけさせること。以下の3カテゴリから**それぞれ最低1つ**選べ：

1. **実用Tips系**：「これ今日から使える」と思わせる具体的な活用法・テクニック
2. **あるある・共感系**：サラリーマンの日常にAIを絡めた共感ネタ。皮肉やユーモアが効く角度
3. **逆張り・問題提起系**：「実はAIでこれは無理」「みんな勘違いしてる」等のツッコミ角度

## 重要
- ただの技術ニュースまとめにしないこと
- 「普通の会社員が読んで面白いと思える角度」を意識すること
- summaryには、記事の要約ではなく「この話のどこが面白いか」「サラリーマンにとっての本音」を書くこと
- 例：
  - ×「OpenAIが新モデルを発表した」
  - ○「API料金40%減。会議の議事録AI化が月ワンコインでできる時代に」
  - ○「GPT-5出たけど、ほとんどの会社員はまだGPT-3.5で十分な件」
  - ○「AI翻訳が完璧になっても、上司の日本語が一番読めない」
- 製造業・工場に限定しないこと。あらゆる業種のビジネスパーソンに刺さる角度で書くこと
- 3テーマが全部「すごいAI→使ってみよう」にならないようにすること

## 出力形式
以下のJSON形式で**のみ**回答してください。説明文や前置きは不要です。

```json
[
  {
    "title": "テーマのタイトル（20文字以内）",
    "summary": "この話の面白いポイントとビジネスでの活用角度（100文字以内）",
    "angle": "tips|aruaru|contrary",
    "key_articles": ["関連記事のURL1", "関連記事のURL2"],
    "relevance_score": 85
  }
]
```

- `angle`: テーマの切り口カテゴリ。`tips`=実用Tips系、`aruaru`=あるある・共感系、`contrary`=逆張り・問題提起系
- relevance_scoreは0-100で、「X投稿にしたときの反応の取れやすさ」を示します。
